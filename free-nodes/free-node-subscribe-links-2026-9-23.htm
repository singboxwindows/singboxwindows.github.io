一、初识Shadowrocket：您的数字通行证

Shadowrocket是一款专为iOS设备设计的代理工具，它巧妙融合了VPN和HTTP代理的技术优势。不同于传统VPN的全局加密，Shadowrocket支持多种代理协议（如Shadowsocks、VMess等），允许用户根据需求灵活选择连接方式。这种模块化设计不仅提升了连接效率，还能针对特定应用或网站进行流量分流，实现更精细化的网络控制。

值得注意的是，Shadowrocket在App Store属于付费应用（目前售价约$2.99）。虽然需要一次性购买，但相比订阅制VPN服务，长期来看反而更加经济。购买前建议确认账户所在地区商店是否上架该应用，部分地区可能需要切换商店区域。

二、从零开始：安装与基础设置

1. 获取应用程序

打开iPhone或iPad的App Store，在搜索栏输入"Shadowrocket"。认准开发者账户为"Shadow Launch Technology Limited"的正版应用，点击获取并完成指纹/面容验证。安装过程通常只需数秒，但需确保设备系统版本在iOS 12以上以获得最佳体验。

2. 首次启动配置

初次启动时，应用会请求VPN配置权限——这是正常且必要的操作，点击"允许"即可。您会看到一个简洁的界面：顶部是连接状态指示器，中部为服务器列表，底部导航栏包含"首页"、"代理"、"全局路由"和"设置"四个功能模块。建议新用户先浏览"设置"中的"使用教程"，这里包含官方提供的图文指引。

三、核心功能详解：打造专属代理方案

1. 服务器配置的艺术

点击右上角"+"号，您将看到丰富的协议选项：
- Shadowsocks：轻量级加密协议，适合移动设备
- VMess（V2Ray核心）：动态端口特性增强隐匿性
- HTTP/HTTPS：适用于普通网页代理
- Trojan：模仿HTTPS流量规避深度检测

以添加Shadowsocks服务器为例：
1. 填写备注名称（如"日本节点1"）
2. 输入服务器IP或域名
3. 正确填入端口号（非443端口需确认防火墙设置）
4. 选择加密方式（推荐AEAD加密如chacha20-ietf-poly1305）
5. 输入密码并保存

专业建议：启用"混淆"选项（Obfs）可让流量伪装成正常HTTPS，特别适用于严格审查的网络环境。

2. 智能路由规则配置

在"全局路由"页面，您可以创建精细化的分流策略：
- 代理模式：仅让指定域名/IP走代理
- 直连模式：国内网站直接连接加速访问
- 阻止模式：屏蔽广告或恶意网站

点击"添加规则"，支持多种匹配方式：
DOMAIN-SUFFIX,google.com,Proxy IP-CIDR,8.8.8.8/32,DIRECT GEOIP,CN,DIRECT
这种配置能实现"国内外智能分流"，既保证访问速度又突破限制。

FAQ

Sing-box 是否兼容 Clash 配置文件？
部分兼容。Sing-box 支持从 Clash 订阅转换工具导入节点，但配置语法略有不同。建议使用第三方订阅转换器，如 sub-converter，将 Clash 格式转换为 Sing-box JSON 格式使用。
SSR 混淆方式如何提升抗封锁能力？
混淆方式可将流量伪装成正常 HTTPS 或 HTTP 数据，降低被 DPI 检测风险。合理选择协议和混淆组合，可以提升节点稳定性和长期可用性，确保科学上网顺畅。
SSR 协议如何配置优化抗封锁？
SSR 可通过选择合适协议、混淆方式和端口来降低被检测风险。合理配置可增强节点隐蔽性，提高长期稳定性，确保科学上网体验顺畅且可靠。
Clash 的策略组如何提升分流效率？
策略组可以将多个节点或规则组合在一起，实现按条件自动选择最佳节点。通过策略组，用户无需手动切换节点即可根据延迟、地理位置或流量类型自动分流，提高网络效率。
PassWall2 的节点测速结果会自动更新吗？
PassWall2 可设置定期自动测速节点，更新延迟和可用性。结合策略组自动选择最优节点，可确保用户使用网络时始终连接到速度最快、最稳定的节点。
Trojan 的伪装域名为什么重要？
伪装域名必须真实可访问且证书有效，以使流量看起来像普通 HTTPS 请求。正确配置可以降低被封锁和 DPI 检测风险，提高节点安全性和长期可用性。
Netch 全局代理与规则代理的适用场景是什么？
全局代理适合游戏或全局科学上网，将所有流量通过节点；规则代理适合只对特定应用或网站进行代理。用户可根据需求选择，提高带宽利用和网络效率。
Matsuri 可以用于 Android 吗？
Matsuri 主要针对桌面平台开发，目前并未推出 Android 版本。但可使用其配置文件在兼容的客户端（如 Nekobox 或 Clash Android）中加载以获得类似体验。
WinXray 的多出口功能如何使用？
WinXray 支持同时配置多个 outbound 节点，并通过路由规则或策略组选择不同出口。这样可以根据流量类型或目的地自动选择节点，实现灵活分流和负载均衡。
Surfboard 与 Shadowrocket 有什么区别？
两者都是 iOS 上的代理工具。Shadowrocket 功能更全面、更新更频繁，而 Surfboard 以轻量和快速见长。若只需简单分流与节点切换，Surfboard 足以满足日常使用。
